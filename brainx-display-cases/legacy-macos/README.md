归档来源：[`chaobrain/BrainX-skill` 的 `yixinliu` 分支](https://github.com/chaobrain/BrainX-skill/tree/a0e377ae225b5de16059f9b51db9aa36b2fad381/brainx-display-cases)，提交 `a0e377a`，于 2026-11-03 导入。

## 可比性

本目录中的历史运行不能与 `../windows-docker/` 下的运行直接比较：执行环境、Codex CLI 版本及 reviewer 通信方式不同。将本目录视为冻结的历史证据；已在此闭环的精炼实验保持归档状态，重新开展的案例必须在 `../windows-docker/` 下建立新基线。
