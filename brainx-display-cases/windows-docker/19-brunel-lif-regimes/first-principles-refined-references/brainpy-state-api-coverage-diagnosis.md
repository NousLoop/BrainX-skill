## Performance and code simplicity

The result uses sparse binary communication, a whole state-aware compiled time loop, small State-owning Modules and lossless bit packing. Three seed processes trade extra graph/compiler memory for independent CPU use; the fine-step group is serial. A synchronized 500-step full-size replay is about 2.98 s cold / 1.73 s warm in the recorded environment. That is not a comparative speedup against the baseline, whose specialization and CPU allocation differ. Reference edits did not prove a global performance improvement; do not infer one from labels or one timing. Generic statistics and file/report code remain outside the neural rollout. No lower precision, smaller model, suppressed unfavorable case or input approximation was used for performance.
