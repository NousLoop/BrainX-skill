# BrainTools spectral API gap — BX-001

- Operation and required capability: exact frozen one-sided Welch PSD of the global rate, 0.1 ms sample interval, 10000-sample (1 s) periodic Hann segments, 5000 overlap, constant detrending separately in each segment, density normalization. Peak frequency, P and Q determine frozen labels, so changing the estimator after outcomes is unacceptable.
- BrainTools APIs checked: full installed BrainPy-State metric routing; official braintools.analysis index; official `braintools.analysis.spectral.power_spectral_density(lfp, dt, nperseg=None, noverlap=None, freq_range=None)` contract. Saved public pages: api-docs/power_spectral_density.txt and api-docs/analysis-index.txt. No installed source or scientific example implementation inspected.
- Observed limitation: the native operation fixes a symmetric Hann window and exposes neither window nor detrend controls. The official contract explicitly documents symmetric Hann versus SciPy’s periodic default. A public-API behavioral comparison on all sixteen saved rate series shows that the native output matches a symmetric-Hann **non-detrended** SciPy reference to relative L2 error at most about 1.15e-7. It does not implement the locked constant detrending. A known 23 Hz sinusoid with constant offset produces native DC power about 6666, versus about 1.4e-28 under the frozen estimator. This is a concrete capability difference, not an unavailable optional dependency.
- Why another routed BrainTools API does not satisfy the contract: the routed/indexed Welch operation is the PSD entry point; coherence, entropy, phase coupling and other analysis functions compute different quantities. Globally subtracting the mean does not equal subtracting each overlapping segment’s mean, and does not address window selection. Rebuilding segmentation, per-segment detrending and window correction around the native API would duplicate the estimator rather than use one named operation.
- Smallest external boundary: retain only the existing `scipy.signal.welch` call in experiment.assess. Inputs are saved population rate magnitudes in Hz/neuron, sample frequency 10000 Hz; outputs are frequency in Hz and PSD in (Hz/neuron)^2/Hz. Model dynamics, input, sparse communication, units and State remain BrainX-native. No raw simulation rerun or scientific specification change is needed.
- Unit, State and shape evidence: public API accepts signal Quantity magnitudes and time quantities. The capability script explicitly supplies canonical Hz/neuron magnitudes, compares dt=0.1 ms to dt=0.0001 s and confirms the same result. Full input shape (30000,16), PSD shape (5001,16); returned frequency grid agrees with the exact 1 Hz grid within float32 rounding. The check is pure postprocessing and reads no mutable model State. Canonical integer frequency-bin centers are used for comparison after verifying the returned grid, avoiding float32 rounding at the fixed band boundaries.
- Numerical parity evidence: spectral_api_check.py re-evaluates the exact frozen estimator for all 16 saved rate series and asserts peak, P and Q agreement with archived metrics to rtol=1e-12 and exact frozen per-run labels. It retains the native alternative, symmetric references and all differences in the analysis-iteration-2 artifacts. Native peaks differ in 12/16 runs, and three fast-SI per-run labels become slow-SI under the unmodified native API because the missing detrending leaks the mean into the 1 Hz bin. These unfavorable differences are preserved, not described as estimator equivalence. The original spectra were also independently recomputed by the reviewer from raw spikes.

Decision: retain the frozen SciPy Welch boundary with this verified capability gap. No model, drive, graph, seed, duration, threshold, displayed case, or scientific conclusion changes. Exact final comparison measurements and hashes are in analysis-iteration-2/verification/.
