# BrainTools spectral capability assessment — BX-001 resolved

The direct `braintools.analysis.spectral.power_spectral_density` operation does not expose the window/detrend settings needed by the frozen estimator. Its documented symmetric-Hann window and measured non-detrended behavior differ from the locked periodic-Hann, per-segment constant-detrended Welch calculation. The preliminary comparison and proposed gap remain preserved in BrainTools-spectral-api-gap-preliminary.md and analysis-iteration-2/verification; that proposed general gap was superseded after checking the other routed APIs.

The official analysis index also provides `braintools.analysis.spectral.spectrogram`. Its contract explicitly supports `window='hann'` (periodic), `detrend='constant'`, `nperseg=10000` and `noverlap=5000`, with per-segment density-normalized PSD in a documented segment axis. Averaging that axis is exactly the locked Welch estimator. This suitable native operation removes the need for a SciPy spectral boundary. `analysis_spectrum.py` now owns the operation and `experiment.assess` calls it.

Checked APIs and public contracts: power_spectral_density, spectrogram, multitaper_psd and band_power, plus the analysis index and the installed BrainPy-State metric routing. Multitaper changes the estimator; band_power returns an integral rather than the full spectrum. The selected spectrogram satisfies all controls. No installed source, scientific examples, papers or existing model implementations were consulted.

Unit/State/shape contract: pass global rate as a Quantity in Hz/neuron, dt as 0.1 ms, time along axis 0. The native segment PSD carries units Hz²/Hz and has shape (5001,5) per run; its mean has 5001 frequency bins. Convert only at the saved-analysis boundary. Verify the returned grid before serializing its exact physical 1 Hz bin centers; this prevents float32 rounding of band boundaries. No mutable neural, input or delay State is read or modified. Offline parity analysis uses float64; archived simulations stay float32.

All cases pass: parity.json and metrics/. All input/source hashes are verified before and after. The original simulation artifacts and unfavorable direct-PSD alternative are preserved. No model parameter, graph, input, seed, duration, threshold, display window, estimator or scientific conclusion changed.
