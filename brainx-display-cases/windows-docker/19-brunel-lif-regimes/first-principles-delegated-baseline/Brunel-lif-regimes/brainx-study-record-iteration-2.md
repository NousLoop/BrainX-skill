## Additional routed API check and revised implementation decision
Before finalizing the proposed gap, the official analysis index routed to `spectral.spectrogram`. Its public contract (api-docs/spectrogram.txt) explicitly supports periodic Hann, constant per-segment detrending, segment length and overlap, and returns each segment’s unit-bearing PSD. Taking the mean over its documented segment axis implements the exact frozen Welch estimator without rebuilding segmentation or FFT logic. `multitaper_psd` changes the estimator; `band_power` returns an integral rather than the full required spectrum. Thus the direct power_spectral_density gap is real, but a general BrainTools spectral capability gap is NOT established. Supersede the preliminary retain-SciPy decision: use BrainTools spectrogram plus its segment mean after validating PSD/P/Q/frequency/label parity against every saved run. Keep preliminary native-PSD comparisons as unfavorable API evidence. Use float64 only in a separate offline analysis process for tight equivalence validation; the neural simulations and their float32 State stay archived unchanged.
