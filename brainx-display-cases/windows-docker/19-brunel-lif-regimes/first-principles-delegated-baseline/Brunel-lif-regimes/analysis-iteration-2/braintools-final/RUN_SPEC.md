# Immutable BrainTools spectral reanalysis

Frozen before execution, reads all sixteen completed parent metric/event-derived rate series. No simulation, raw input edits, condition/seed selection, threshold changes or estimator changes. BrainTools spectrogram with periodic Hann and constant detrending, averaged over its segment axis, replaces the SciPy spectral boundary. Explicit unit-bearing Hz input and ms dt, one-sided PSD converted to canonical Hz²/Hz. Offline analysis alone enables JAX float64 for tight parity; neural model arrays remain archived float32. Every frequency bin, PSD, P, Q, peak and frozen label is compared to archived results, including fine-dt data rebinned to 0.1 ms. Stop on any tolerance or label mismatch. Input/source hashes in config.json; command in command.txt; expected native metrics/arrays, parity.json, log and exit_code. Parent results and unfavorable preliminary native-PSD comparisons remain preserved.
