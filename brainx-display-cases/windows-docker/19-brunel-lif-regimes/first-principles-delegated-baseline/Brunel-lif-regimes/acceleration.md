# Acceleration evidence
The full stateful rollout is compiled with BrainState jit(for_loop). BrainEvent CSR visits active presynaptic edges. Spike history is packed into bits in the compiled loop, preserving every event at fixed memory cost (1563 bytes/bin).

Measured the full-size 100 ms smoke with dynamic condition scalars and with static condition scalars. Compile-time specialization of g and eta removes a runtime Poisson-distribution branch without changing the model, parameters, input counts or event order. Exact packed spikes and final membrane voltages match between both executions: acceleration.json. Component compiled/uncompiled spike, membrane, refractory, RNG-key and seeded-replay parity: checks.json. Timing separates compile and warm execution. Full-size warm time fell from 3.51 s to 1.31 s in this smoke; no scientific outcome was inspected or used to choose this optimization. CPU affinity experiment did not improve dynamic execution and is not used.

The condition and seed loops are independent rollouts, each with one compiled time loop and a complete stable-identity State snapshot reset. No Python time loop, dense recurrent matrix, altered degrees, input approximation or model rescaling. Initial and final RNG values use public key_data serialization; every run starts at its recorded seed, with exact full-rollout replay tested. No mid-rollout resume is claimed.

Production correction: eager public sparse-operator initialization before tracing prevents its lazy workspace from retaining a tracer across static-condition compilations. checks-final.log verifies compilation of another condition and exact replay. corrected_execution_parity.json confirms bit-for-bit identity of the entire first full-size production trajectory (including burn-in, final membrane/refractory State and RNG key) before and after this execution-only correction. The failed parent run remains archived. The frozen scientific specification is unchanged.
