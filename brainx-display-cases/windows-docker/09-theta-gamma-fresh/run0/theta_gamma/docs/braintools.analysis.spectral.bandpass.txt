A Butterworth band-pass of order order (an IIR filter of order 2 * order ) is designed on the host as second-order sections with scipy.signal.butter(order, band, btype='band', fs=fs, output='sos') .
The signal is filtered forward and backward [ 1 ] , which squares the
magnitude response and cancels the phase, exactly as scipy.signal.sosfiltfilt with its defaults: odd extension of padlen = 3 * (2 * n_sections + 1 - n_zero) samples
at both ends, where n_zero counts sections with a trivial last
coefficient; initial states sosfilt_zi(sos) * x[0] for the forward pass and sosfilt_zi(sos) * y[-1] for the backward pass. Parameters : x ( Array | ndarray | bool | number | bool | int | float | complex | Quantity ) – Real signal of shape (T, ...) ; time is axis 0. A brainunit.Quantity is accepted. dt ( float | Quantity ) – Sampling interval (seconds if a plain number). Static. band ( Tuple [ float , float ] ) – Pass band (low, high) in Hz with 0 < low < high < fs / 2 .
Static. order ( int ) – Butterworth order (number of second-order sections). Static. Returns : y – Filtered signal with the shape, dtype and unit of x . Return type : Array | Quantity Raises : ValueError – If a band edge is <= 0 or >= fs / 2 , order < 1 , or T <= padlen (the signal is too short for the edge padding, the
    same condition under which SciPy raises). See also analytic_signal Hilbert-transform analytic signal. plv Phase-locking value, optionally after band-passing. Notes Both passes run as a single jax.lax.scan over time that cascades all
sections at each step (direct form II transposed), so the cost is
sequential in T . The function is jittable, vmappable and (being linear)
differentiable with respect to x . In float32, low cut-offs relative to fs lose precision; use float64 for very narrow or very low bands. References [ 1 ] Gustafsson, F. “Determining the initial states in forward-backward
filtering.” IEEE Transactions on Signal Processing 44.4 (1996):
988-992.
